# Кто занимает первые этажи новостроек Санкт-Петербурга

Независимое исследование коммерческих помещений в жилых комплексах Санкт-Петербурга, сданных в 2021–2025 гг.:
структура арендаторов (общепит, продукты, beauty, фитнес, медицина, услуги) по классам жилья и районам.

> Статус: в работе (октябрь 2026).

## Данные
- **ДОМ.РФ (наш.дом.рф)** — сданные многоквартирные дома СПб, класс жилья, координаты, срок ввода.
  Ответы сохранены вручную через браузер в `data/raw/domrf/` (в репозиторий не входят).
- **OpenStreetMap** — выгрузка Geofabrik «Northwestern Federal District» (`data/raw/osm/*.osm.pbf`, © участники OpenStreetMap, ODbL).

## Структура
```
src/            скрипты по шагам (00_… разведка, 03_… извлечение OSM, …)
data/raw/       исходные выгрузки (не в git)
data/interim/   промежуточные файлы (не в git)
data/processed/ итоговые таблицы
output/         графики и карты
report/         дайджест и полная версия отчёта (PDF)
```

## Как воспроизвести
1. Python 3.9+; `pip install -r requirements.txt`
2. Скачать `northwestern-fed-district-latest.osm.pbf` с download.geofabrik.de → `data/raw/osm/`
3. Сохранить ответы ДОМ.РФ (список ссылок — будет добавлен) → `data/raw/domrf/`
4. `python3 src/03_osm_extract.py` и далее по номерам.
